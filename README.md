# 🌦️ Power BI Real-Time Weather Analytics Dashboard

## 📌 Overview
This project showcases a **real-time analytics dashboard built using Power BI**, designed to fetch, transform, and visualize live weather data. The solution integrates external APIs and structured datasets to deliver **actionable insights through interactive dashboards**, focusing on real-time weather conditions in **Hyderabad**.

This project demonstrates hands-on experience with **API integration, data transformation, DAX modeling, and dashboard design**, making it suitable for **Business Intelligence and Data Analytics** use cases.

---

## 📊 Data Sources
- **OpenWeather API**
  - Fetches real-time weather data including temperature, humidity, pressure, and weather conditions.
- **External Data Files**
  - Supporting datasets imported into Power BI for enhanced analysis.

---

## ⚙️ Project Workflow & Methodology

### 1️⃣ Data Collection
- Integrated Power BI with the **OpenWeather REST API**.
- Imported external datasets into Power BI Desktop.

### 2️⃣ Data Transformation
- Cleaned and structured data using **Power Query Editor**.
- Removed inconsistencies, handled missing values, and standardized formats.

### 3️⃣ Data Modeling & Calculations
- Created calculated columns and measures using **DAX**.
- Built KPIs and aggregations to support trend analysis.

### 4️⃣ Data Visualization
- Designed interactive dashboards using:
  - KPI cards
  - Line and bar charts
  - Filters and slicers
- Focused on clarity, usability, and real-time monitoring.

### 5️⃣ Insights & Analysis
- Analyzed real-time weather trends.
- Identified anomalies and fluctuations.
- Enabled data-driven decision-making.

## 🧩 Installation & Setup

1. **Install Power BI Desktop**  
   Download from: https://powerbi.microsoft.com/

2. **Open the Project**
   - Load the provided `.pbix` file in Power BI Desktop.

3. **Configure API Key**
   - Open **Power Query Editor**
   - Replace the existing OpenWeather API key with your own key.

4. **Refresh Data**
   - Click **Refresh** to load the latest real-time data.
